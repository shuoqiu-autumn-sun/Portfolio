STM32 Custom PCB

Designed and layout a custom STM32 development board featuring an integrated MPU-6050 6-axis IMU, USB-C power, and SWD debugging capabilities.

Motivation

I designed a custom STM32 development board by following a YouTube tutorial to build intuition for electrical design while strengthening my skills in Altium and becoming familiar with its features. This project also served as an introduction to the STM32 ecosystem, providing a structured starting point for learning embedded systems development.

Overview

This project was my first step into working with STM32 microcontrollers after previously only using Arduino. I chose to follow an existing STM32 tutorial as a structured way to get started, since it allowed me to focus on learning the basics of schematic design, PCB layout, and firmware bring-up without overcomplicating the board. The goal was to build a simple, reliable development board using an STM32F4 and a small set of supporting components, and to use the project as a way to build intuition around embedded system design.

Schematic & Component Selection

All capacitors, resistors, LEDs, and crystals are SMD to match MCU speed, enable proper decoupling, and allow cleaner and smaller layout.

Microcontroller (STM32F4)

STM32F411CEU6 MCU (U2)

  • 2.2uF Capacitor 0603 (C7, C13):
    • C7: Bulk capacitor stabilizing 3.3 V supply against low-frequency transients.
    • C13: Required capacitor for STM32 internal core voltage regulator stability.
  • 10pF Capacitor 0402 (C5, C6): Crystal load capacitors ensuring stable oscillation and correct frequency.
  • 100nF Capacitor 0402 (C8-C12, C14):
    • C8-C12: Local decoupling capacitors suppressing high-frequency switching noise at VDD.
    • C14: NRST line noise filtering and reset signal stabilization.
  • Red LED 0402 (D2): Visual indicator for firmware status and debugging.
  • Debugging Cable (J2): Provides SWD programming, debugging, reset, and power reference access.
  • Header Connector (J3): External peripheral connector supplying power, ground, and GPIO signals.
  • 1kOhm Resistor 0402 (R5): Limits current through MCU status LED to safe levels.
  • 0kOhm Resistor 0402 (R2): For oscillator debugging or trace impedance tuning.
  • 2.2kOhm Resistor 0402 (R3-R4): I²C pull-up resistors defining logic-high levels on SDA and SCL.
  • 10kOhm Resistor 0402 (R6-R7):
    • R6: Pull-down resistor keeping NRST low during power-up conditions.
    • R7: BOOT0 pull-up selecting normal Flash boot mode.
  • 24MHz Crystal (X1): Provides accurate external clock for STM32 system timing.

USB Connector and LDO Regulator (+5V to +3V3)

  • USB Connector (J1): Provides USB power, data signals, and ground from host device.
  • AMS1117 Voltage Regulator (U1): Linear regulator converting 5 V USB supply to stable 3.3 V.
  • 2.2uF Capacitor 0603 (C1-C2):
    • C1: Bulk capacitor smoothing USB VBUS voltage fluctuations.
    • C2: Input decoupling capacitor improving regulator stability and noise rejection.
  • 22uF Capacitor 0402 (C3-C4):
    • C3: Additional bulk capacitance supporting regulator transient current demands.
    • C4: Output capacitor ensuring AMS1117 stability and low output ripple.
  • Green LED 0402 (D1): Indicates presence of regulated 3.3 V power rail.
  • 120Ohm Ferrite Bead 0603 (FB1): Filters high-frequency noise from USB VBUS before regulator input.
  • 1kOhm Resistor 0402 (R1): Limits current through power LED to safe operating level.

Inertial Measurement Unit (MPU-6050)

MPU 6050 Gyro (U3) (I2C Addr.: 0x68)

  • 100nF Capacitor 0402 (C15-C16):
    • C15: Filter noise and stabilize internal voltage regulator.
    • C16: Decoupling capacitor.
  • 10nF Capacitor 0402 (C17): Allow clean digital signaling.
  • 2.2uF Capacitor 0603 (C18): Energy transfer element for charge pump.
